# Elementa — Hear the Elements · 元素之声

**Light is 40 octaves above sound.** Elementa is a periodic table you can play: every element's real emission
spectrum is shifted down exactly 40 octaves (f = c / λ / 2⁴⁰) into sound. Hydrogen plays its four Balmer lines,
sodium hums its yellow doublet (listen for the 0.5 Hz beat), neon rings in deep red.

**Play it:** https://wojiaozyh123-hub.github.io/elementa/

- Tap or drag across the table to strum the elements
- Daily Ear Test — can you tell sodium from neon by ear?
- Spell any word in element symbols and hear it
- Pure physics or tuned to the nearest piano key · visible light or UV → IR

Data: NIST Atomic Spectra Database — *Handbook of Basic Atomic Spectroscopic Data* (Sansonetti & Martin).
