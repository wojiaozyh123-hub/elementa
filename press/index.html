Facts · 事实

WhatA periodic table you can play: each element's real emission spectrum, shifted down exactly 40 octaves into sound.
一张能弹的元素周期表：把每种元素真实的发射光谱整体降低 40 个八度，变成声音。
Physics · 公式f = c / λ / 2⁴⁰. Visible light (380–780 nm) becomes about 350–718 Hz, roughly one octave.
Data · 数据NIST Atomic Spectra Database, Handbook of Basic Atomic Spectroscopic Data (strong lines); 118 elements, 97 with measured lines.
